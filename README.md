# Bank Access Simulator

A Python-based program that simulates a simple bank card access system.

## Features

- Password verification
- Maximum login attempts
- Remaining attempt counter
- Automatic card locking
- Login and logout system
- Password change functionality
- Password confirmation
- Basic password validation
- Interactive account menu

## Technologies

- Python
- While Loops
- Conditional Statements
- Variables
- String Operations
- User Input
